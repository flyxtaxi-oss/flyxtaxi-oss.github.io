# Dossier Immo Maroc — démonstration publique

Site statique fictif en lecture seule : présentation, dossier d'exemple et CRM 3D de démonstration. La scène 3D utilise trois contacts codés en dur et ne communique avec aucune API. Aucun compte, donnée client ou document privé. Le produit authentifié reste un prototype local non ouvert au public. Source applicative privée : flyxtaxi-oss/dossier-immo-maroc.
